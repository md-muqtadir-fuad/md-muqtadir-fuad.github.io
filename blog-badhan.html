Automating Blood Donor Management with Python & Selenium for Badhan

How I built a resilient web automation workflow to parse batch donation registries and automate portal entry for a nationwide voluntary blood donation organization.

Open Source Contribution

Badhan Web Automation Script: Automated bulk donor record ingestion and form validation pipeline contributed to the Badhan BUET Zone codebase.

View Pull Request #86 →

Badhan is a prominent voluntary blood donation organization operating across educational institutes in Bangladesh, with its central roots at BUET. Every semester, Badhan organizes large-scale blood grouping drives and donation camps, collecting vital donor data to support patients in critical emergency conditions.

However, converting paper collection forms or raw spreadsheets from drives into the centralized Badhan database was historically done through manual web form submissions. Volunteers had to copy and paste hundreds of entries line by line—a tedious process highly susceptible to typos in phone numbers and blood groups.

The Solution Architecture

To solve this operational bottleneck, I built an automated ingestion script using Python, Pandas, and Selenium WebDriver. The automation pipeline executes in four structured stages:

  • Data Cleansing & Normalization: Reads batch CSV/Excel registries, standardizes blood group nomenclature (e.g., handling variations like "A+", "A positive", "A(+)"), strips whitespace, and verifies 11-digit Bangladeshi mobile number patterns using regular expressions.
  • Authenticated Session Handling: Automatically logs into the authorized administrative dashboard, stores session tokens, and navigates to the donor registry forms.
  • Automated Form Ingestion: Populates student ID, hall name, contact details, blood group, donation availability, and last donation timestamps using explicit DOM waits.
  • Exception Logging & Audit Trail: If a donor entry fails (e.g., duplicate record or network drop), the script captures a screenshot, logs the row index and error reason, and continues without terminating the batch.

Technical Challenges & Resilience

Automating modern web interfaces requires handling subtle UI dynamics:

Key Engineering Techniques:

  • • Explicit Waits via WebDriverWait and expected_conditions instead of brittle static sleep timers.
  • • Jittered rate-limiting between form submissions to avoid triggering server-side DDoS tripwires.
  • • Fallback selector hierarchies (ID → Name → Relative XPath) to survive minor UI refactors.

Impact & Contribution

The automation script slashed donor record registration time from several volunteer-hours per campaign down to mere minutes, eliminating transcription errors and ensuring that fresh blood donor data is instantly queryable during emergency requests.
